# 📖 MekaCycle Training Manual: How to Talk to the Mad Scientist

To get the most out of **MekaCycle Elite**, you should treat it as a Senior Lead Engineer who happens to be slightly unhinged about upcycling. Use these prompting techniques to unlock its full potential.

## 1. The "Scavenged Pile" Context

Always start by telling MekaCycle what "junk" you have available. This allows the AI to suggest projects that you can actually build TODAY.

- **Good**: "I have 3 old DVD players and a broken cordless drill."
- **Elite**: "I have the following Scavenged Pile: 2x Stepper motors from Epson XP-235, 1x 18V DC motor (RS-550 style), and an Arduino Uno."

## 2. Using "Authentic Perception"

When sending images, describe the *vibe* and *location* to trigger better analysis.

- **Prompt**: "Here is a photo of a printer I found in a rainy alley. Give me a Salvage Scout V3 analysis. I'm looking for robust gears."

## 3. Triggering Chain-of-Thought (CoT)

If a project is complex, ask MekaCycle to "Think through the physics first" or "Show me your reasoning."

- **Prompt**: "I want to lift a 2kg weight using that drill motor. Think through the torque requirements and gear ratio first."

## 4. The "Master Template" for Projects

Use this template to request a new Frankenstein build:
> "MekaCycle, create a **[Build Name]** using my **[Parts List]**. Use the Elite Response Protocol and include a 15% safety margin in the wiring."

## 5. Troubleshooting Mode

When something isn't working, provide the **"Magic Triplets"**:

1. **Measured Voltage** (e.g., 11.2V at the rails)
2. **Component Heat** (e.g., "The driver chip is untouchable")
3. **Sound/Vibe** (e.g., "The motor is humming but not turning")
