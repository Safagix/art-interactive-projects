# Art Interactive Projects

Carpeta para proyectos creativos, arte interactivo, interfaces visuales, musica, cuerpo digital, videojuegos, realidad mixta/virtual y experimentos audiovisuales.

Esta carpeta separa estos trabajos de los proyectos principales de IA aplicada, RAG, agentes, automatizacion y estudio tecnico.

## Proyectos movidos aqui

- `air-canvas`: dibujo gestual con manos/camara, MediaPipe, Three.js y objetos 3D interactivos.
- `cuerpo`: cuerpo/avatar digital de Eira, capas visuales, animacion y lip-sync.
- `MR`: Codice, VisionEngine, Godot, Cardboard VR, gestos, passthrough y HUD holografico.
- `musicgen_lab`: laboratorio de generacion musical/audio con MusicGen.
- `MekaCycle`: notas de proyecto creativo/tecnico con motores, pantallas y recuperacion de componentes.
- `open-design`: diseno visual, sistema de diseno, assets y tooling creativo.
- `portfolio`: portfolio visual/interactivo.
- `ProfessionalStats`: interfaz visual con React, Three.js, React Three Fiber y animaciones.
- `UI_UX_Components`: componentes y recursos de UI/UX.
- `Eira_Poliglota`: se mantiene aqui por su parte expresiva, voz, avatar/personaje y narrativa interactiva.

## TouchDesigner

Los archivos `.toe` de TouchDesigner no se publican en este repositorio. La experiencia esta documentada como parte del perfil creativo: hice piezas de arte interactivo en tiempo real con TouchDesigner, musica, camara e interaccion con manos.

## Regla de organizacion

Mover aqui proyectos cuando el foco sea arte, experiencia, interfaz visual, cuerpo, audio, performance, videojuego, realidad mixta/virtual/aumentada o narrativa interactiva.

Dejar fuera proyectos cuyo foco principal sea RAG, agentes, automatizacion empresarial, infraestructura IA, estudio tecnico o tooling de productividad.
