# Art Interactive Projects

This repository is a small archive of experiments where software becomes a body, a stage, an instrument, or a visual system.

It gathers the projects from Digital Lab that are not mainly about backend AI infrastructure, RAG pipelines, or automation. The focus here is experience: hands in front of a camera, sound reacting to a system, interfaces that feel alive, mixed-reality sketches, avatars, motion, game worlds, and visual prototypes.

## What This Is

`Art Interactive Projects` is a public-safe collection of creative technology work:

- gesture interfaces
- camera-based interaction
- immersive and expanded interfaces
- virtual and mixed reality sketches
- audiovisual experiments
- digital bodies and avatars
- UI systems with expressive motion
- creative tooling and visual research
- interactive narrative prototypes

The projects are rough in places, because they are lab pieces. They are meant to show process, curiosity, and direction rather than a single polished product.

## Project Map

### `air-canvas`

A hand-tracking drawing space built around camera input, MediaPipe, Three.js, and interactive 3D objects. It explores the idea of drawing directly in the air, using the hand as both pointer and brush.

### `cuerpo`

Digital body and avatar experiments for Eira. This includes visual layers, facial states, animation assets, audio analysis, and lip-sync style prototypes.

### `MR`

Mixed reality and virtual reality experiments around Codice, VisionEngine, Godot, Cardboard VR, gesture control, passthrough concepts, and holographic HUD interfaces.

### `musicgen_lab`

A small music and audio generation lab. It keeps early work around generated sound, listening systems, and audiovisual direction.

### `MekaCycle`

Creative technical notes for a hardware-inspired project space: motors, screens, salvage components, design thinking, and speculative machine-building.

### `open-design`

Design tooling, visual systems, UI experimentation, and creative infrastructure. This folder represents the visual language and interface research side of the lab.

### `portfolio`

A portfolio-style interface experiment for presenting the work with stronger visual rhythm and interaction.

### `ProfessionalStats`

A React interface experiment with animated systems, dashboards, cognitive training concepts, and game-like personal progression.

### `UI_UX_Components`

Reusable UI and UX component notes: animated docks, story scrolls, prompt boxes, liquid glass buttons, cursor-reactive panels, and visual interaction patterns.

### `Eira_Poliglota`

Included here because Eira is not only an assistant prototype. It is also a character, a voice, an interface, and an interactive presence.

## TouchDesigner Note

TouchDesigner files are not published in this repository.

The practice is still part of the creative profile behind this archive: I have built real-time interactive art pieces with TouchDesigner using music, camera input, and hand interaction. This repository documents the broader direction without publishing the original `.toe` project files.

## Why This Exists

Digital Lab is split into different kinds of work. Some projects are about AI systems, local assistants, or retrieval infrastructure. This repository is for the other side: the expressive side.

The question behind these projects is simple:

> What happens when code stops being only a tool and starts becoming a space you can touch, hear, perform, or inhabit?
