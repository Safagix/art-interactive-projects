# PROMPT PARA STITCH: ProfessionalStats UI Design

Copia y pega el siguiente prompt en Stich para generar la interfaz de la V3:

---

**PROMPT:**

Actúa como un diseñador de interfaces de élite especializado en estética técnica y futurista. Necesito que diseñes el Dashboard principal de una aplicación de gamificación profesional llamada "ProfessionalStats".

**ESTILO VISUAL REQUERIDO:**

- **Estética:** Frutiger Aero v2 + Apple "Liquid Glass" (Glassmorphism Pro Max).
- **Atmósfera:** Holística, premium, tipo "Esports Player Profile" pero para la vida real.
- **Acabado:** Paneles de cristal con desenfoque de fondo profundo (Backdrop Blur), bordes ultra-delgados e iluminados, gradientes vibrantes y texturas orgánicas/glossy.

**PALETA DE COLORES Y TIPOGRAFÍA:**

- **Fondo:** Deep Obsidian Navy (Obsidian Mesh Gradient).
- **Acento Principal:** Aero Blue (#4FC3F7) con un brillo holográfico.
- **Estados:** Éxito en Neon Green, Peligro en Valorant Red, Legendario en Oro líquido.
- **Fuentes:** "Space Mono" para valores numéricos y rangos; "DM Sans" para legibilidad de cuerpo.

**ESPECIFICACIONES DEL LAYOUT (Dashboard Central):**

1. **Persistent Sidebar:** Navegación minimalista con iconos de Lucide (Dashboard, Rango, Skill Tree, Misiones, Config).
2. **Header de Perfil:** Un widget premium que muestre: Nivel Actual (en un anillo circular de cristal), XP Total, Racha de Días (icono de fuego con brillo) y Título de Rango (ej: "Novice" o "Ascendant").
3. **Radar Chart Dinámico (Key Visual):** Un gráfico de radar octogonal (u N-lados) situado en el centro o derecha, con ejes para "Frontend", "Backend", "Fitness", "Finanzas", etc. El área del gráfico debe estar rellena con un gradiente aero-blue translúcido.
4. **Skill Cards:** Grid de tarjetas de cristal que contengan: Icono representativo, Nombre de la habilidad, Barra de progreso de XP (estilo glow) y un Badge de Rango pequeño (ej: un diamante para Diamante, un escudo para Hierro).
5. **Bounty Board (Misiones):** Lista vertical de tareas. Si es la primera del día, mostrar una cinta dorada que diga "⚡ FIRST GRIND - 2X XP". Cada misión debe indicar dificultad (Fácil/Experto) y tiempo.
6. **Activity Heatmap:** Un gráfico de contribución tipo GitHub (90 días) pero con celdas de cristal azulado.

**DETALLES UX / MICRO-INTERACCIONES:**

- Los elementos deben parecer "flotar" sobre el fondo.
- Utiliza sombras difusas y capas de refracción de luz para dar la sensación de cristal líquido de Apple.
- Las barras de progreso deben tener un efecto de "escaneo" o brillo que las recorre.

**OBJETIVO EMOCIONAL:** Que el usuario sienta que cada pequeña acción en el mundo real lo hace subir de nivel en un sistema de alta tecnología impecable.
