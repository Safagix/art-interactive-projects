## 🤖 LLM Self-Hosting Tools (Ollama Alternatives)

### **Jan** ⭐

- **Repositorio:** <https://github.com/janhq/jan>
- **Web:** <https://jan.ai/>
- **Características:**
  - Desktop app nativa (Windows/Mac/Linux)
  - UI moderna estilo ChatGPT
  - Gestión de modelos integrada
  - Compatible con GGUF models
- **Uso:** Alternativa a Ollama con mejor UI
- **Prioridad:** ⭐⭐ MEDIA (si Open WebUI no es suficiente)

### **LM Studio** ⭐

- **Repositorio:** <https://github.com/lmstudio-ai>
- **Web:** <https://lmstudio.ai/>
- **Características:**
  - Descarga modelos con 1 click
  - Optimizado para CPU y GPU
  - API compatible con OpenAI
  - Gestión avanzada de contexto
- **Uso:** Más fácil que Ollama para principiantes
- **Prioridad:** ⭐⭐⭐ ALTA (reemplazo de Ollama recomendado si quieres UI superior)

### **llama.cpp** ⭐

- **Repositorio:** <https://github.com/ggerganov/llama.cpp>
- **Características:**
  - Implementación C++ pura de LLMs
  - Ultra-optimizado para CPU
  - Base de Ollama y otros runners
  - Cuantización GGUF nativa
- **Uso:** Backend para desarrolladores avanzados
- **Prioridad:** ⭐ BAJA (Ollama ya lo usa internamente)

### **KoboldCpp** ⭐

- **Repositorio:** <https://github.com/LostRuins/koboldcpp>
- **Características:**
  - llama.cpp + API + GUI
  - Especial para roleplaying/storytelling
  - Compatible con Kobold API
  - Excelente para narrativa generativa
- **Uso:** Si deseas que Eira cuente historias interactivas
- **Prioridad:** ⭐⭐ MEDIA (funcionalidad específica)

### **oobabooga (Text-Generation-WebUI)** ⭐

- **Repositorio:** <https://github.com/oobabooga/text-generation-webui>
- **Características:**
  - WebUI completa para LLMs locales
  - Soporte extensivo de modelos
  - Extensiones/plugins disponibles
  - Chat, notebook, y server modes
- **Uso:** Alternativa robusta a Ollama con más opciones
- **Prioridad:** ⭐⭐ MEDIA (avanzado)

### **GPT4All** ⭐

- **Repositorio:** <https://github.com/nomic-ai/gpt4all>
- **Web:** <https://www.nomic.ai/gpt4all>
- **Características:**
  - Desktop app simple
  - Colección curada de modelos optimizados
  - Muy fácil de usar
  - Funciona 100% offline
- **Uso:** Opción "plug-and-play" para quien no quiere configurar nada
- **Prioridad:** ⭐⭐ MEDIA (simplicidad)

### **llamafile** ⭐

- **Repositorio:** <https://github.com/Mozilla-Ocho/llamafile>
- **Características:**
  - Ejecuta LLMs en un SOLO archivo
  - No requiere instalación
  - Multiplataforma
  - Ideal para portabilidad
- **Uso:** Ejecutar modelos sin dependencias
- **Prioridad:** ⭐ BAJA (para testing rápido)

### **AnythingLLM**

- **Repositorio:** <https://github.com/Mintplex-Labs/anything-llm>
- **Web:** <https://anythingllm.com/>
- **Características:**
  - RAG (Retrieval-Augmented Generation) integrado
  - Gestión de documentos
  - Embeddings locales
  - Multi-user workspace
- **Uso:** Si deseas que Eira "lea documentos" y responda basándose en ellos
- **Prioridad:** ⭐⭐⭐ ALTA (feature killer para productividad)

### **LibreChat**

- **Repositorio:** <https://github.com/danny-avila/LibreChat>
- **Web:** <https://librechat.ai/>
- **Características:**
  - Clón de ChatGPT con soporte multi-modelo
  - Plugin system
  - Conversaciones con archivos
- **Uso:** UI familiar tipo ChatGPT
- **Prioridad:** ⭐⭐ MEDIA

### **Leon** (AI Assistant Framework)

- **Repositorio:** <https://github.com/leon-ai/leon>
- **Web:** <https://getleon.ai/>
- **Características:**
  - **Framework completo de AI Assistant**
  - Módulos de skills (clima, música, productividad)
  - TTS/STT integrados
  - 100% open-source, privacidad total
- **Uso:** **COMPETIDOR DIRECTO DE EIRA** - Considera migrar o inspirarte
- **Prioridad:** ⭐⭐⭐ CRÍTICA (¡revisar arquitectura!)

## 🖼️ Image Generation (Stable Diffusion Local)

### **Stability Matrix** ⭐

- **Repositorio:** <https://github.com/LykosAI/StabilityMatrix>
- **Web:** <https://lykos.ai/>
- **Características:**
  - Manager de UIs de Stable Diffusion
  - 1-click install de ComfyUI, Fooocus, etc.
  - Gestión de modelos centralizada
- **Uso:** Generación de assets visuales para Eira UI
- **Prioridad:** ⭐⭐ MEDIA (si necesitas generar imágenes)

### **ComfyUI** ⭐

- **Repositorio:** <https://github.com/comfyanonymous/ComfyUI>
- **Web:** <https://www.comfy.org/>
- **Características:**
  - Node-based workflow (como Blender)
  - Muy eficiente en RAM
  - Funciona en CPU (lento) o GPU
- **Uso:** Generación avanzada de imágenes
- **Prioridad:** ⭐ BAJA (no prioritario para Eira/Códice)

### **Fooocus** ⭐

- **Repositorio:** <https://github.com/lllyasviel/Fooocus>
- **Características:**
  - Simplificado, estilo Midjourney
  - Sin configuración compleja
  - Mejor para CPU que otros
- **Uso:** Generación simple de imágenes
- **Prioridad:** ⭐ BAJA

### **Automatic1111 (AUTOMATIC1111/stable-diffusion-webui)** ⭐

- **Repositorio:** <https://github.com/AUTOMATIC1111/stable-diffusion-webui>
- **Características:**
  - WebUI más popular para Stable Diffusion
  - Extensiones masivas
  - Compatible con todas las herramientas SD
- **Uso:** Estándar de oro para imagen local
- **Prioridad:** ⭐⭐ MEDIA (si necesitas generar muchas imágenes)

## 🔊 Audio Processing (Local)

### **Ultimate Vocal Remover (UVR)**

- **Repositorio:** <https://github.com/Anjok07/ultimatevocalremovergui>
- **Características:**
  - Separación de voz/música/instrumentos
  - Múltiples modelos (MDX, Demucs, VR)
  - Alta calidad de separación
- **Uso:** Limpiar audio de micrófono con ruido de fondo
- **Prioridad:** ⭐⭐ MEDIA (calidad de vida para Eira)

### **MDX23** (Superior a UVR)

- **Repositorio:** <https://github.com/jarredou/MVSEP-MDX23-Colab_v2>
- **Características:**
  - Modelo de separación de última generación
  - Mejor que UVR en benchmarks
  - Funciona local con GPU o CPU
- **Uso:** Limpieza de audio profesional
- **Prioridad:** ⭐⭐ MEDIA

## 🚀 Recomendaciones Inmediatas

### **Para Eira (Crítico):**

1. **Investigar Leon AI Framework**
   - Comparar arquitectura con Eira actual
   - Evaluar si vale la pena migrar o adoptar componentes
   - Ventaja: Skills system ya implementado

2. **Instalar AnythingLLM**
   - Capacidad RAG = Eira puede "leer documentos"
   - Ejemplo: "Eira, resume este PDF"
   - Instalación: `git clone https://github.com/Mintplex-Labs/anything-llm`

3. **Considerar LM Studio como reemplazo de Ollama**
   - UX superior (_drag-and-drop_ modelos)
   - Mejor gestión de memoria en Ryzen 3
   - Descarga: <https://lmstudio.ai/>

   - Elimina ruido de fondo del micrófono
